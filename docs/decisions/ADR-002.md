# ADR-002: Hosting

Status: accepted 9 Nov 2026; partly built. Last reviewed 11 Nov 2026.

## Context
A state-DOT user needs a fast, always-on map. The project has no budget and one fixed public URL.

## Decision
- The site stays at **https://horus331.github.io/mass-flood-watch/** (GitHub Pages from `docs/`). The URL never changes.
- Small JSON on Pages; large per-run frames (5-min depth images, 20 m tiles) on the `frames-<prefix>` branches, served via
  raw.githubusercontent.com and pointed to by `meta.data_base` (`tools/frames_push.sh`), so `main` stays small.
- `/status/` shows the storm state and the freshness of every source.
- Planned: PMTiles vector tiles for the road layer, `status.json` polling every 60 s in the viewer, a `/staging/` preview path.

## Alternatives
A server (rejected: cost, upkeep); Git LFS (rejected: bandwidth quota).

## Consequences
Branch pushes for frames must stay one orphan commit per prefix (current + previous cycle) to keep the repository small.
