## 2. Gaps against the master prompt

1. **Named baselines are not built:**
   - NWS FFW polygons
   - FEMA 100-year floodplain
   - MassDOT repeating points as a predictor
   - a tuned rainfall threshold
   - HAND / depression index
   - H×V×C

   Today the only comparison is against random.
2. **Metrics.**
   - Missing: POD, FAR, CSI at stated thresholds; Brier score / BSS against each baseline; reliability diagrams.
   - CIs are 90 % and two-stage. The prompt asks for 95 % bootstrapped over storms.
   - The positive–unlabeled treatment is implicit (unreported roads are counted as dry). It needs a stated rule.
3. **Probability per segment per 6 h window:**
   - The k-of-8 count exists. Depth quantiles, onset, duration and main driver are not in the output.
   - There are no soil or culvert ensemble members, and no HREF / NBM / RRFS members.
4. **States:** QUIET/WATCH/ACTIVE are not named as such; today's states are quiet / run / forced. There is no /status page and no per-source "next update".
5. **Archive:** it lives in the git repo (`docs/proto/archive`). There is no Hugging Face dataset, no Zenodo DOI, and no immutable per-issue manifest with container hash.
6. **Reliability:**
   - No container, and no golden-storm regression in CI (only a w9 self-test on synthetic data).
   - No ADRs, RUNBOOK or CHANGELOG.
   - Failures don't open GitHub Issues.
7. **Product:**
   - Missing: crew checklist ranked by risk × consequence, ArcGIS / GeoJSON / shapefile export, storm digest, planning mode, Validation page.
   - Exists: the CSV and road list.
8. **Parametric study (clogged culverts, saturated or frozen soil):**
   - The 32 Leominster what-if scenarios exist (5-min, T2).
   - Not yet framed as "value of maintenance" or run on under-predicted storms.
9. **Resilience:** the Ganin delay and access metrics exist for Leominster. Section-level pavement resilience and repair cost are not built.
