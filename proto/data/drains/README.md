# Leominster storm-drain network

`leominster_drain_pipe.zip`: City of Leominster DPW storm-drain pipe layer (Drain_Pipe), shared with the project in Oct 2026 and published here with the City's agreement.
Used by `sim/colab/lf_drains.py` to give each grid cell a drain sink capped by Manning full-flow pipe capacity (`proto/turing/run_drains.slurm`).
